PRAGITHA SURPRISE WEBSITE 💗

FILES
- index.html: complete website (CSS and JavaScript are embedded)
- images/pragitha1.png, images/pragitha2.jpg, images/pragitha3.jpg: your uploaded photos
- soft-melody.mp3: optional; add your own properly licensed audio file in this folder

LOCAL PREVIEW
Keep the folder structure intact, then open index.html in a modern browser. For best results, preview through a local web server or after hosting.

FREE HOSTING WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository named pragitha-surprise.
2. Upload index.html, the images folder with all three photos, and optionally soft-melody.mp3 to the repository root.
3. Open the repository's Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish and copy the URL shown in Settings → Pages.
6. Open the URL on your phone to test it, then share the link.

TROUBLESHOOTING
- Missing photos: filenames and capitalization must match exactly. Keep the images folder beside index.html.
- No music: add a properly licensed file named soft-melody.mp3 beside index.html. Music starts only after the visitor taps Play melody.
- Layout issue: use an updated Chrome, Firefox, Safari, or Edge browser. The page adapts to mobile screens and respects reduced-motion preferences.
- Photo privacy: anyone with the published link may be able to view the photos. Share thoughtfully and only with consent.
